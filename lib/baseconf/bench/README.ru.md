# Замеры вывода шрифтов

[![English](https://img.shields.io/badge/lang-en-blue.svg)](README.en.md)
[![Русский](https://img.shields.io/badge/lang-ru-green.svg)](README.ru.md)

Команда `make -C lib/baseconf/bench` запускает замер в ZX256, а
`make -C lib/baseconf/bench BENCH_MODE=4` запускает замер в ATM640. Раннер считывает частичный
счётчик T-state Z80 в ZEsarUX между точками останова.

Бенчмарк рисует 64 непрозрачных символа `p` через функцию дескриптора шрифта. В ZX256 позиции шрифта
5×8 циклически меняются между x=0, 6, 12 и 18, задействуя четыре битовых смещения внутри байта. В
ZX256 измеряются font5 и font8, результат сохраняется в
`lib/baseconf/bench/build/font-draw-bench-0-results.json`. В ATM640 измеряется font5, результат
сохраняется в `lib/baseconf/bench/build/font-draw-bench-4-results.json`. Эмулятор выбирается
переменной `ZESARUX`. Для сборки TAP нужен appmake из SDK.
[Требования appmake](../../../tools/appmake/README.ru.md)

### Исторические замеры

Реализации на C и Z80 сравнивались на одинаковой нагрузке в ZX256. Текущий бенчмарк измеряет
реализацию, с которой собрана библиотека.

| Реализация   | T-state на 64 символа | T-state на символ |
| ------------ | --------------------: | ----------------: |
| font5 на C   |             1 338 989 |          20 921,7 |
| font5 на Z80 |               357 309 |           5 583,0 |
| font8 на C   |               734 445 |          11 475,7 |
| font8 на Z80 |               618 797 |           9 668,7 |

В этих замерах реализация на Z80 ускорила font5 примерно в 3,75 раза, а font8 в 1,19 раза.
Исторический результат font5 в ATM640 составил 2 304 066 T-state, или 36 001 на символ.
