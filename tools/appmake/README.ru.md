# Расширение z88dk appmake для BaseConf

[English](README.en.md)

В этом каталоге находятся упаковщик `+baseconf` и патч его регистрации в z88dk appmake. Для сборки
укажите каталог исходников z88dk.

```sh
Z88DK_SRC=/path/to/z88dk/src make -C tools/appmake
```

Скрипт копирует исходники appmake в локальный `build/`, применяет
`patches/baseconf-registration.patch`, добавляет `baseconf.c` и собирает инструмент. После сборки
временная копия удаляется. Исходное дерево z88dk остаётся на месте. Результат находится в
`tools/appmake/build/z88dk-appmake`, а `make -C tools/appmake clean` удаляет его.

Нужны C-компилятор для хоста, `make`, `patch` и файлы разработки GMP. Скрипт берёт флаги GMP из
`pkg-config`, если он доступен, и использует `-lgmp` при отсутствии флагов линковки. В `Z88DK_SRC`
должны быть `appmake/`, `common/dirname.c`, `common/dirname.h` и `config.h`.

## Происхождение и лицензия

Упаковщик разрабатывался для z88dk версии `26724-9fc3cae210-20261103`. Через `Z88DK_SRC` можно
указать другое совместимое дерево. Скрипт выводит версию при сборке. Исходники appmake и их
уведомления берутся из этого дерева. Лицензия z88dk Clarified Artistic License находится в файле
`LICENSE` на уровень выше `Z88DK_SRC`. Патч фиксирует изменение регистрации, а исходник нового
упаковщика находится в этом репозитории.

## Использование

Конфигурация BaseConf в SDK уже указывает локальный инструмент через `APPMAKEEXE`. В Makefile
приложения подключите `lib/baseconf/baseconf.mk` из SDK и передайте `-Cz+baseconf` для упаковки TAP
с банковыми секциями.

```makefile
	$(ZCC) $(BASECONF_APP_FLAGS) -m -create-app -Cz+baseconf -Cz--name=MYPROGRAM \
	  -o build/program src/main.c
```

Для упаковки уже слинкованной программы вызовите инструмент напрямую.

```sh
tools/appmake/build/z88dk-appmake +baseconf \
  --binfile build/program --crt0file build/program --output build/program.tap
```

Файл карты и бинарники секций должны лежать рядом и иметь стандартные имена z88dk appmake. Упаковщик
берёт адреса и размеры из карты линковки.

## Формат TAP и загрузка

- TAP содержит токенизированный загрузчик Spectrum BASIC и стандартные блоки CODE.
- Загрузчик и основной блок по умолчанию называются `BASECONF`. Опция `--name=NAME` или флаг zcc
  `-Cz--name=NAME` задаёт имя из 1–10 символов. Поле дополняется до 10 байт. Имена банков по
  умолчанию имеют вид `BANK000`–`BANK255`. Для другого префикса из 1–7 символов используйте
  `--bank-prefix=PREFIX` или `-Cz--bank-prefix=PREFIX`.
- Инициализированные секции основного банка собираются в один образ с нулевым заполнением
  промежутков. BSS не входит в загрузочный образ.
- Загрузчик рассчитывает, что ERS/BAS48 уже настроил режим RAM и частоту CPU, и не пишет в `FF77`
  или `EFF7`. Для каждой группы `BANK_n` он открывает теневой порт BaseConf, отображает физическую
  страницу `n` в W3 (`C000–FFFF`) без подстановки и восстанавливает `BF`. Это сохраняет точку
  перехвата ленты ERS. Номер страницы для `BANK_XX` берётся из старшего байта адреса z80asm.
- По умолчанию загрузка начинается с первой инициализированной секции, а `USR` входит по символу
  `start`. При отсутствии `start` используется адрес загрузки. `start` включает код запуска CRT.
  `__CODE_head` указывает на начало кода после CRT. Значение `CLEAR` по умолчанию равно `0x5fff`.
  Адреса переопределяются через `--org`, `--usraddr` и `--clearaddr`.
- Секции каждого банка объединяются в образ для W3 размером до 16 КиБ. Банки загружаются по
  возрастанию номеров. Основной образ должен помещаться в 16-битном адресном пространстве. Страницы
  переключает загрузчик BASIC до передачи управления программе.
