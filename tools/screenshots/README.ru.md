# Скриншоты эмулятора

[![English](https://img.shields.io/badge/lang-en-blue.svg)](README.en.md)
[![Русский](https://img.shields.io/badge/lang-ru-green.svg)](README.ru.md)

`capture.py` загружает собранный TAP для BASIC 48 или SPG для TSConf в отдельном процессе ZEsarUX и
сохраняет экран в PNG. Поддерживаются программы для TSConf, BaseConf и Spectrum 48K, без привязки к
именам примеров SDK и структуре каталогов. Банковые TAP загружаются через свой BASIC-загрузчик.
Утилита не собирает программы и не запускает тестовые наборы.

Требуются Python 3 (только стандартная библиотека) и ZEsarUX с поддержкой ZRCP. Эмулятор выбирается
через `--zesarux`, переменную `ZESARUX` или PATH. Pillow не требуется.

## Использование

Запуск из корня репозитория; входной файл, снимок и лог могут находиться в любых каталогах:

```sh
python3 tools/screenshots/capture.py --machine TSConf \
  --tap path/to/program.tap --output build/program.png

python3 tools/screenshots/capture.py --machine BaseConf \
  --tap lib/baseconf/build/examples/night_train.tap --output build/night_train.png

python3 tools/screenshots/capture.py --machine 48K --entry 0x9000 \
  --tap path/to/spectrum.tap --output build/spectrum.png --instructions 500000

python3 tools/screenshots/capture.py --spg path/to/program.spg --output build/program.png
```

`--spg` использует штатный SPG-загрузчик ZEsarUX через команду ZRCP `smartload`. Поддерживается
заголовок SpectrumProg 1.0; распаковкой блоков и установкой состояния машины занимается эмулятор.
Для SPG доступен только TSConf. Адрес входа берётся из файла, поэтому `--entry` передавать нельзя.
Стартовые/загрузочные клавиши BASIC и их задержки пропускаются. `--instructions`, ввод в приложение
и сохранение PNG работают одинаково для TAP и SPG. Это запуск через загрузчик эмулятора, а не через
TS-BIOS с диска или SD.

TAP должен содержать BASIC-загрузчик, запускающий программу по адресу `--entry` (по умолчанию
`0x8000`). Утилита запускает BASIC, вводит `LOAD ""`, ждёт точки входа, затем исполняет
`--instructions` команд процессора и делает снимок. Счётчики задают **инструкции Z80**, а не такты,
кадры или миллисекунды. Для программ с автоматическим возвратом в BASIC уменьшите задержку; для
загрузки ресурсов и переходов увеличьте её.

Для ввода в программу задайте последовательность клавиш через точку с запятой:

```sh
python3 tools/screenshots/capture.py --machine TSConf \
  --tap path/to/program.tap --output build/program.png \
  --keys 'enter;h;e;l;l;o;space;w4;right'
```

Поддерживаются буквы, цифры, `space`, `enter`, `caps`, `sym`, `up`, `down`, `left`, `right`, `load`,
`quote` и `break`. `caps+space` удерживает сочетание клавиш, `right~100000` — клавишу на указанное
число инструкций, `w4` ждёт четыре интервала отпускания клавиш. Ввод выполняется после начальной
задержки `--instructions`. Затем проходит задержка `--after-key-instructions` и снимается экран. Без
`--keys` последняя задержка пропускается.

| Параметр                      | Значение по умолчанию / назначение                                                    |
| ----------------------------- | ------------------------------------------------------------------------------------- |
| `--machine`                   | `TSConf`; также `BaseConf`, `48K`                                                     |
| `--tap` / `--spg`, `--output` | Один обязательный входной файл и PNG; родительские папки создаются автоматически      |
| `--entry`                     | `0x8000`; адрес входа CPU, десятичный или шестнадцатеричный с `0x`                    |
| `--instructions`              | `6000000`; выполнение до ввода в программу или съёмки                                 |
| `--after-key-instructions`    | `500000`; выполнение после ввода в программу                                          |
| `--boot-instructions`         | `2000000`; инициализация ROM до стартовых клавиш                                      |
| `--load-instructions`         | `2000000`; лимит до достижения точки входа после ввода команды BASIC                  |
| `--key-instructions`          | `50000`; длительность нажатия клавиши                                                 |
| `--key-settle-instructions`   | `50000`; выполнение после отпускания, единица ожидания для `wN`                       |
| `--startup-keys`              | Для BaseConf: `i;w8`, для остальных пусто; можно заменить для другого меню ROM        |
| `--load-keys`                 | `load;quote;quote`; клавиши до завершающего Enter, который отправляется автоматически |
| `--rom`                       | Необязательный файл ROM выбранной платформы                                           |
| `--log`                       | `build/screenshots/<имя-входного-файла>.log`, относительно текущей папки              |
| `--zesarux`                   | Исполняемый файл эмулятора                                                            |

При старте TSConf отображается страница 3 ROM BASIC 48, отключаются кэш CPU и DOS, включается
кадровое прерывание. На BaseConf клавиша `i` выбирает BASIC, Spectrum 48K загружается в BASIC
напрямую. Для нестандартной прошивки могут потребоваться другие стартовые клавиши или команда
загрузки TAP. Утилита поддерживает TAP BASIC 48 и SPG 1.0 для TSConf; дисковые образы и другие
форматы снапшотов она не запускает.

Захват использует `tools/zesarux/runner.py`: ZRCP сохраняет BMP, затем стандартная библиотека
преобразует его в PNG без потерь. Сохраняются бордюр и штатный масштаб пикселей эмулятора.
Существующие снимок и лог перезаписываются; после завершения выводятся абсолютные пути. Для
нескольких программ с одинаковым именем задавайте разные `--log`.
